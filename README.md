# claude-config

Personal Claude Code configuration — settings, scripts, and custom commands.

## Setup

On any machine with Claude Code installed:

```bash
cd ~/.claude && git clone https://github.com/cdesjardins/claude-config.git .
```

## Contents

- `settings.json` — model, statusline, and plugin configuration
- `scripts/` — statusline and other helper scripts
- `commands/` — custom slash commands
- `plugins/` — plugin configuration
